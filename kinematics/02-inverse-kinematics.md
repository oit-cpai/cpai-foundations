手先を目標の位置 $\bm{p}^\ast = (x, y)^\top$ に持っていきたい。モーターに指令するには、そのための関節角 $\bm{q}$ が必要である。このように、手先の位置から関節角を求める計算を**逆運動学**という。

順運動学(K1)では、関節角を決めれば手先の位置はただ1つに決まった。逆運動学はそうではない。**解が2つあることも、1つのことも、ないこともある**。この単元では、2リンク平面アームの逆運動学を式で解き(解析解)、解の数がどう変わるかを確かめる。リンクの長さは K1 と同じ $l_1 = 1.0$ 、 $l_2 = 0.8$ とする。

## 1. $q_2$ を求める:余弦定理

K1 の式 (3) で見たとおり、原点から手先までの距離 $r$ は $q_2$ だけで決まる。

```math
r^2 = l_1^2 + l_2^2 + 2 l_1 l_2 \cos q_2
```

これを $\cos q_2$ について解く。目標の位置では $r^2 = x^2 + y^2$ なので、

```math
\cos q_2 = \frac{x^2 + y^2 - l_1^2 - l_2^2}{2 l_1 l_2} \qquad (1)
```

である。右辺を $c$ と書く。

- $\lvert c \rvert > 1$ なら、 $\cos q_2 = c$ となる $q_2$ はない。目標は**到達可能領域の外**にある。K1 の式 (4) と同じ条件である
- $\lvert c \rvert \le 1$ なら、 $q_2 = \arccos c$ と $q_2 = -\arccos c$ の**2つ**が解になる

`np.arccos` は $0$ から $\pi$ までの角度を返す。 $\cos(-\theta) = \cos\theta$ なので、符号を変えた $-\arccos c$ も式 (1) を満たす。

## 2. 2つの解

$q_2 > 0$ の解と $q_2 < 0$ の解は、ベースと目標を結ぶ線について**鏡に映した関係**になる。肘は、片方の解では線の右側に、もう片方では左側に出る。

```text
             肘(q2 < 0 の解)
            ●
          /   \
        /       \
      ◎─────────● 目標
        \       /
          \   /
            ●
             肘(q2 > 0 の解)
```

よく「肘が上の解(elbow-up)」「肘が下の解(elbow-down)」と呼ぶ。ただし、どちらが上になるかは、目標の位置と $q_2$ の向きの決め方で変わる。そのため、この単元では **$q_2$ の符号**で2つの解を呼び分ける。どちらの解で肘がどちらに出るかは、notebook で図を描いて確かめる。

解が1つになるのは、 $c = \pm 1$ のとき、つまり目標が到達可能領域の境界にあるときである。

- $c = 1$( $`r = l_1 + l_2`$):アームがまっすぐ伸びた姿勢( $q_2 = 0$)だけ
- $c = -1$( $`r = \lvert l_1 - l_2 \rvert`$):肘を折りたたんだ姿勢( $q_2 = \pi$)だけ

## 3. $q_1$ を求める:`atan2`

$q_2$ が決まれば、 $q_1$ は K1 の式 (2) から求まる。

```math
\bm{p}^\ast = R(q_1) \begin{pmatrix} l_1 + l_2 \cos q_2 \\ l_2 \sin q_2 \end{pmatrix}
```

右のベクトルの向きの角度を $\beta$ 、目標の向きの角度を $\alpha$ とする。 $R(q_1)$ はベクトルを $q_1$ だけ回すので、 $\alpha = q_1 + \beta$ である。よって、

```math
q_1 = \alpha - \beta = \operatorname{atan2}(y,\ x) - \operatorname{atan2}(l_2 \sin q_2,\ l_1 + l_2 \cos q_2) \qquad (2)
```

となる。 $q_2$ の2つの解のそれぞれについて、式 (2) で $q_1$ を1つずつ求める。

### `atan2` を使う理由

ベクトル $(x, y)$ の向きの角度を、 $\arctan(y / x)$ で計算してはいけない。

- $\arctan$ は $-\pi/2$ から $\pi/2$ までの角度しか返さない。 $(1, 1)$ と $(-1, -1)$ は、 $y / x$ が同じ 1 なので、同じ角度になってしまう
- $x = 0$ のとき、割り算ができない

`np.arctan2(y, x)` は、 $x$ と $y$ の符号から4つの象限を区別し、 $-\pi$ から $\pi$ までの正しい角度を返す。**引数の順番は $y$ が先**である。

## 4. 求めた関節角を確かめる

逆運動学で求めた関節角は、必ず**順運動学に戻して**、目標の位置になるかを確かめる。

```math
\lVert \mathrm{fk}(\bm{q}) - \bm{p}^\ast \rVert \approx 0
```

関節角そのものを答えと比べるのは避ける。 $q_1 = \pi$ と $q_1 = -\pi$ のように、 $2\pi$ だけ違う角度は同じ姿勢を表すからである。

## 5. 数値の計算で気をつけること

- **境界での丸めの誤差**:目標が外側の境界( $`r = l_1 + l_2`$)にあると、式 (1) の $c$ が、計算の丸めの誤差で `1.0000000000000002` のように 1 をわずかに超えることがある。このとき `np.arccos` は `nan` を返す。 $\lvert c \rvert$ が 1 をごくわずかに超えるだけなら、 $c$ を 1(または $-1$)にそろえてから `np.arccos` を使う
- **角度の跳び**:目標を少しずつ動かして、そのたびに逆運動学を解く。すると、 $q_1$ が $\pi$ の近くで急に $-\pi$ に跳ぶことがある。 `atan2` が $-\pi$ から $\pi$ までの値しか返さないためで、姿勢は跳んでいない。関節角の時系列として使うときは、 `np.unwrap` でつなぎ直す

## 6. 研究で使うときは

- **どちらの解を使うか**:2つの解のどちらを使うかは、関節の可動範囲、障害物、今の姿勢から近いほう、などで決める。強化学習で行動を手先の位置で表すときも、この選び方を決めておく必要がある
- **解析解が使えないとき**:関節が3つ以上ある空間アームでは、式で解けないことが多い。そのときは、M3 §6 で見た一次近似をくり返す方法(数値逆運動学、K4)を使う。解析解は、数値逆運動学の結果が正しいかを確かめる「正解」としても使える
