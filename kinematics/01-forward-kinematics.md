# K1 2リンク平面アームの順運動学

| 項目 | 内容 |

| 到達目標 | 2リンク平面アームの関節角から、肘と手先の位置を計算できる。関節角が「相対角」であることを説明できる。手先が届く範囲(到達可能領域)が円環になることを、式と図で説明できる |
| 前提 | M1(三角関数、内積とノルム、回転行列) |
| 時間の目安 | 本文 1時間、notebook 1.5〜2時間 |
| 使う場面 | ロボットアームのシミュレーション、強化学習の状態と行動の設計、K2(逆運動学)・K4(数値逆運動学) |
| notebook | [`01_forward_kinematics.ipynb`](01_forward_kinematics.ipynb) |

ロボットアームを動かすとき、モーターに指令できるのは**関節の角度**である。一方、作業で大事なのは**手先の位置**である。関節角から手先の位置を求める計算を**順運動学**、手先の位置から関節角を求める計算を**逆運動学**(K2)という。この単元では、いちばん簡単な2リンクの平面アームで、順運動学を式と図で確かめる。

## 1. 2リンク平面アーム

```text
                    ● 手先 (x, y)
                   /
             l2   /  ← 第2リンク
                 /
   肘 ●---------    q2 は、第1リンクの向きから測った角度
     /
 l1 /  ← 第1リンク
   /   q1 は、x 軸から測った角度
  ◎ ベース(原点)────────→ x
```

| 言葉 | 意味 |
|---|---|
| リンク | 関節と関節をつなぐ棒。長さを $`l_1, l_2`$ とする |
| 関節 | リンクを回す部分。ベースと肘に1つずつある |
| 関節角 | 関節の回転の角度 $`q_1, q_2`$ 。2つをまとめて $`\bm{q} = (q_1, q_2)^\top`$ と書く |
| 手先 | アームの先端。物をつかむ部分 |
| 自由度 | 独立に動かせる関節変数の数。このアームは 2 |

角度はすべて**ラジアン**で、反時計回りを正とする(M1 §4)。この単元では $l_1 = 1.0$ 、 $l_2 = 0.8$ を使う。

> [!IMPORTANT]
> $q_2$ は x 軸からの角度ではなく、**第1リンクの向きから測った角度**(相対角)である。モーターは、自分がついているリンクに対して回るからである。 $q_2 = 0$ のとき、アームはまっすぐに伸びている。

## 2. 肘の位置

肘は、原点から長さ $l_1$ のリンクを、角度 $q_1$ の向きに伸ばした先にある。

```math
\bm{p}_{\mathrm{e}} = l_1 \begin{pmatrix} \cos q_1 \\ \sin q_1 \end{pmatrix}
```

## 3. 手先の位置

第2リンクは、第1リンクの向き $q_1$ から、さらに $q_2$ だけ回っている。したがって、x 軸から見た第2リンクの向きは $`q_1 + q_2`$ である(**相対角は足し算になる**)。手先の位置は、肘の位置に第2リンクのベクトルを足したものである。

```math
\bm{p} = l_1 \begin{pmatrix} \cos q_1 \\ \sin q_1 \end{pmatrix} + l_2 \begin{pmatrix} \cos(q_1 + q_2) \\ \sin(q_1 + q_2) \end{pmatrix} \qquad (1)
```

これが2リンク平面アームの**順運動学**である。 $\bm{q}$ を決めれば、 $\bm{p}$ はただ1つに決まる。

### 回転行列で見る

式 (1) は、M1 の回転行列 $R(\theta)$ を使って次のようにも書ける。

```math
\bm{p} = R(q_1) \begin{pmatrix} l_1 + l_2 \cos q_2 \\ l_2 \sin q_2 \end{pmatrix} \qquad (2)
```

右のベクトルは、「第1リンクを x 軸に重ねて見たときの手先の位置」である。それを、アーム全体として $q_1$ だけ回したものが手先の位置になる。式 (2) は K2 で $q_1$ を求めるときに使う。

> [!TIP]
> 式 (2) を展開すると式 (1) に戻る。加法定理 $`\cos(q_1 + q_2) = \cos q_1 \cos q_2 - \sin q_1 \sin q_2`$ を使って確かめるとよい。

## 4. 手先までの距離は $q_2$ だけで決まる

原点から手先までの距離 $r = \lVert \bm{p} \rVert$ を求める。式 (2) で、回転行列はベクトルの長さを変えない(M1 §4)ので、

```math
r^2 = (l_1 + l_2 \cos q_2)^2 + (l_2 \sin q_2)^2 = l_1^2 + l_2^2 + 2 l_1 l_2 \cos q_2 \qquad (3)
```

となる。距離は $q_2$ だけで決まり、 $q_1$ には関係しない。

- $q_2$ は肘の曲げ具合を決める。肘を曲げるほど、手先は原点に近づく
- $q_1$ はアーム全体の向きを決める。 $q_2$ を固定して $q_1$ を回すと、手先は半径 $r$ の円を描く

> [!NOTE]
> 式 (3) は、ベース・肘・手先の三角形に余弦定理を使った式と同じである。内積で書くと、 $`r^2 = \lVert \bm{a} + \bm{b} \rVert^2 = \lVert \bm{a} \rVert^2 + \lVert \bm{b} \rVert^2 + 2\,\bm{a}^\top \bm{b}`$ ( $\bm{a}, \bm{b}$ は2本のリンクのベクトル)で、 $`\bm{a}^\top \bm{b} = l_1 l_2 \cos q_2`$ である。

## 5. 到達可能領域

手先が届く点の集まりを**到達可能領域**(ワークスペース)という。

- 式 (3) で、 $\cos q_2$ は $-1$ から $1$ まで動く。したがって距離 $r$ は、 $`\lvert l_1 - l_2 \rvert`$(肘を折りたたんだとき、 $q_2 = \pi$)から $`l_1 + l_2`$(まっすぐ伸ばしたとき、 $q_2 = 0$)までの値をとる
- $q_1$ を一回りさせると、どの向きにも届く

よって、関節が自由に回るとき、到達可能領域は内側の半径 $`\lvert l_1 - l_2 \rvert`$ 、外側の半径 $`l_1 + l_2`$ の**円環**(ドーナツの形)になる。この単元のアームでは、内側の半径 0.2、外側の半径 1.8 である。

```math
\lvert l_1 - l_2 \rvert \le \lVert \bm{p} \rVert \le l_1 + l_2 \qquad (4)
```

### 関節の可動範囲

実際のアームでは、関節が回れる角度に限りがある(**可動範囲**、関節の制限)。たとえば $q_2$ が $0 \le q_2 \le 2\pi/3$ しか動けないと、式 (3) から、手先は原点からある距離より近くに来られなくなる。到達可能領域は、式 (4) の円環より狭くなる。

> [!WARNING]
> 強化学習でアームに目標の位置を与えるとき、目標が到達可能領域の外にあると、どんなに学習しても届かない。目標を作るときは、式 (4) と可動範囲を必ず確かめる。

## 6. 研究で使うときは

- **状態や行動をどう選ぶか**:アームの強化学習では、行動を「関節角の変化」にすることも、「手先の位置の変化」にすることもできる。後者を選ぶと、行動を関節の指令に直すために逆運動学(K2・K4)が必要になる
- **シミュレーションの確かめ方**:シミュレータの関節角と手先の位置が、式 (1) と合うかを確かめると、座標の向きや角度の単位(度とラジアン)の間違いを早く見つけられる

## 7. 確認課題

1. $l_1 = 1.0$ 、 $l_2 = 0.8$ とする。次の関節角のとき、肘と手先の位置を手計算せよ。 $\bm{q} = (0, 0)$ 、 $(\pi/2, -\pi/2)$ 、 $(0, \pi/2)$ 、 $(\pi/2, \pi/2)$
2. $q_2$ が x 軸からの角度ではなく相対角であることは、式 (1) のどこに表れているか
3. 式 (2) を展開して、式 (1) と一致することを確かめよ
4. $`l_1 = l_2`$ のとき、到達可能領域はどんな形になるか。原点に手先を置けるか
5. $q_2$ の可動範囲が $0 \le q_2 \le 2\pi/3$ のとき、手先が届く範囲の内側の半径を求めよ
