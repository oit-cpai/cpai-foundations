実験データには、特徴量がたくさんあることが多い(関節の角度が7つ、センサーの値が20個など)。しかし、それらは互いに関係していて、本当に独立に動いている方向は少ないことがある。**主成分分析**(PCA)は、データのばらつきが大きい方向を順に見つけ、少ない次元でデータを表す。

## 1. ばらつきの大きい方向

$N$ 個のデータを行に並べた行列 $X$(形 $N \times D$ 、S2 のデータ行列)を考える。各列の平均 $\bar{x}$ を引いたもの(**中心化**)を $X_c$ とする。長さ 1 の方向 $u$ にデータを射影すると、各データの座標は $X_c u$ で、その分散は

```math
\frac{1}{N} \lVert X_c u \rVert^2 = u^\top S u, \qquad S = \frac{1}{N} X_c^\top X_c \qquad (1)
```

である。 $S$ は**共分散行列**(形 $D \times D$ 、対称)で、 $u^\top S u$ は M8 の二次形式である。

分散が最大の方向を求めるには、 $\lVert u \rVert = 1$ のもとで $u^\top S u$ を最大にすればよい。ラグランジュの未定乗数法を使うと、条件は

```math
S u = \lambda u \qquad (2)
```

となる。つまり、 $u$ は $S$ の**固有ベクトル**で、そのときの分散 $u^\top S u = \lambda$ は**固有値**である。分散が最大の方向は、最大の固有値の固有ベクトルである。

- **第1主成分**:最大の固有値 $\lambda_1$ の固有ベクトル $u_1$
- **第2主成分**: $u_1$ と直交する方向の中で、分散が最大の方向。2番目に大きい固有値の固有ベクトル $u_2$
- 以下同様。 $S$ は対称なので、固有ベクトルどうしは直交する

## 2. 手順

1. **中心化**:各列の平均を引く
2. **共分散行列**: $`S = X_c^\top X_c / N`$
3. **固有分解**:固有値と固有ベクトルを求め、固有値の大きい順に並べる

> [!WARNING]
> 対称行列の固有分解には `np.linalg.eigh` を使う(`eig` より速く、結果が実数で返る)。ただし、`eigh` は固有値を**小さい順**に返すので、大きい順に並べ替える。固有ベクトルの向き(符号)は決まらない。 $u$ と $-u$ は同じ主成分である。

## 3. 寄与率:何次元残すか

固有値 $\lambda_j$ は、第 $j$ 主成分の方向の分散である。全体の分散(各列の分散の和)は、固有値の和に等しい。

```math
\text{寄与率}_j = \frac{\lambda_j}{\sum_{i=1}^{D} \lambda_i}
```

上位 $M$ 個の寄与率の和(**累積寄与率**)が、たとえば 90% を超える最小の $M$ を選ぶ。

## 4. 射影と再構成

上位 $M$ 個の固有ベクトルを列に並べた行列 $U_M$(形 $D \times M$)を使うと、

```math
Z = X_c\, U_M \quad (\text{形 } N \times M), \qquad \hat{X} = Z\, U_M^\top + \bar{x} \qquad (3)
```

$Z$ が低次元の座標(**主成分得点**)、 $\hat{X}$ が $M$ 次元の情報だけから元に戻したもの(**再構成**)である。再構成の誤差(1つのデータあたりの、距離の2乗の平均)は、

```math
\frac{1}{N} \sum_n \lVert x_n - \hat{x}_n \rVert^2 = \sum_{j = M+1}^{D} \lambda_j \qquad (4)
```

と、**捨てた主成分の固有値の和**になる。PCA は「分散を最も多く残す」方法であると同時に、「再構成の誤差を最も小さくする」方法でもある。

> [!TIP]
> 式 (4) は、実装を確かめるのに使える。再構成の誤差が、捨てた固有値の和と一致しなければ、どこかが間違っている(notebook §3)。

## 5. SVD との関係

中心化したデータ行列を特異値分解(M8)すると、 $X_c = U \Sigma V^\top$ となる。このとき、

```math
S = \frac{1}{N} X_c^\top X_c = V \frac{\Sigma^2}{N} V^\top
```

なので、 $V$ の列が主成分の方向、 $\sigma_j^2 / N$ が固有値である。実際のライブラリは、 $S$ を作らずに SVD で計算することが多い(数値的に安定で、 $D$ が大きいときも速い)。

## 6. 前処理

- **中心化は必ず行う**:平均を引かないと、第1主成分が「原点からデータの中心への方向」になってしまう
- **単位がそろっていなければ標準化する**:分散の大きい特徴量(たとえば mm で測った長さ)が、第1主成分をほぼ独り占めする。単位の違う特徴量を混ぜるときは、各列を標準偏差で割ってから PCA を行う(相関行列の固有分解になる)
- **PCA は直線の方向しか見つけない**:データが曲がった面の上にある場合は、少ない次元で表しきれない(カーネル PCA、t-SNE、UMAP などの方法がある)

## 7. 研究で使うときは

- 強化学習で、エージェントが訪れた状態や、方策のネットの隠れ層の出力を PCA で2次元にして描くと、学習の進み方や、方策の違いを眺められる
- 回帰(S2)の入力が多く、似た入力がある(多重共線性)ときに、主成分を入力にする方法がある(主成分回帰)
- scikit-learn の `PCA` は、この単元と同じことをする(`n_components`、`explained_variance_ratio_` が寄与率、`transform` と `inverse_transform` が式 (3))。標準化は `StandardScaler` で、学習用のデータだけで平均と標準偏差を決める(S6)

## 8. 研究室のライブラリ `cpai_lab` との関係

`cpai_lab` には、PCA の関数は入っていない。`cpai_lab` の環境で集めた状態や、`ExperimentRun` で保存した実験の記録を、この単元の方法で可視化できる。
