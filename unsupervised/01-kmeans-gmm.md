## 1. クラスタリング

$N$ 個の点 $`x_1, \dots, x_N`$(それぞれ $D$ 次元のベクトル)を、 $K$ 個のグループに分けたい。 $K$ は先に決めておく。

## 2. k-means

各クラスタの**中心** $\mu_k$ を考え、各点を最も近い中心のクラスタに入れる。「点と、その点が属するクラスタの中心との距離の2乗」の和

```math
J = \sum_{n=1}^{N} \lVert x_n - \mu_{k(n)} \rVert^2 \qquad (1)
```

を小さくしたい。 $k(n)$ は点 $n$ が属するクラスタの番号である。次の2つを交互にくり返す。

1. **割り当て**:中心を固定して、各点を最も近い中心のクラスタに入れる
2. **更新**:割り当てを固定して、各クラスタの中心を、そこに属する点の平均にする

どちらの手順でも、 $J$ は増えない(1. は各点について距離を最小にし、2. は平均が「距離の2乗の和」を最小にする点だから)。したがって、 $J$ は単調に減り、有限回で止まる。

> [!WARNING]
> **止まった所が、いちばん良い答えとは限らない**(局所的な最小)。初めの中心の選び方で、結果が変わる。初めの中心を変えて何回か実行し、 $J$ が最も小さいものを選ぶ。また、どの点も割り当てられないクラスタ(空のクラスタ)ができたら、中心を適当な点に置き直すなどの処理が必要である。

## 3. 混合ガウス分布

k-means は、各点を1つのクラスタにはっきり割り当てる。2つのクラスタの境目にある点も、どちらか一方に入れてしまう。また、クラスタの広がり方(細長い、大きい、小さい)を考えない。

**混合ガウス分布**は、データが次のように作られたと考える。

1. 確率 $\pi_k$ でクラスタ $k$ を選ぶ( $`\sum_k \pi_k = 1`$)
2. そのクラスタの正規分布 $`\mathcal{N}(x \mid \mu_k, \Sigma_k)`$ から点を作る( $\mu_k$ は平均、 $\Sigma_k$ は共分散行列で、広がりの形と向きを表す)

すると、点 $x$ の確率密度は

```math
p(x) = \sum_{k=1}^{K} \pi_k\, \mathcal{N}(x \mid \mu_k, \Sigma_k) \qquad (2)
```

である。点 $x_n$ がクラスタ $k$ から作られた確率は、条件付き確率(M2 §4、ベイズの定理)で

```math
\gamma_{nk} = \frac{\pi_k\, \mathcal{N}(x_n \mid \mu_k, \Sigma_k)}{\sum_{j} \pi_j\, \mathcal{N}(x_n \mid \mu_j, \Sigma_j)} \qquad (3)
```

と計算できる。 $\gamma_{nk}$ を**負担率**という(各点について、 $k$ について足すと 1)。

## 4. EM アルゴリズム

パラメータ $`\pi_k, \mu_k, \Sigma_k`$ を、対数尤度 $`\sum_n \log p(x_n)`$ を最大にするように選びたい(最尤推定。S5 §3)。直接は解けないので、k-means と同じように、2つの手順を交互にくり返す。

1. **E ステップ**:今のパラメータで、負担率 $\gamma_{nk}$ を式 (3) で計算する
2. **M ステップ**:負担率を重みとして、各クラスタのパラメータを、重みつきの平均で計算し直す

```math
N_k = \sum_n \gamma_{nk}, \qquad \pi_k = \frac{N_k}{N}, \qquad \mu_k = \frac{1}{N_k} \sum_n \gamma_{nk}\, x_n, \qquad \Sigma_k = \frac{1}{N_k} \sum_n \gamma_{nk} (x_n - \mu_k)(x_n - \mu_k)^\top \qquad (4)
```

$N_k$ は「クラスタ $k$ に属する点の数」を、負担率で数えたものである。このくり返しで、**対数尤度は単調に増える**(減らない)。

> [!TIP]
> **実装の確かめ方**:くり返しのたびに対数尤度を記録し、減っていないかを確かめる。少しでも減ったら、どこかが間違っている。k-means の $J$ も同じで、増えたら間違いである。

## 5. k-means と混合ガウス分布の関係

| | k-means | 混合ガウス分布 |
|---|---|---|
| 割り当て | はっきり1つ(ハード) | 確率で(ソフト。負担率) |
| クラスタの形 | 中心からの距離だけ(丸い) | 共分散行列で、細長い・傾いたクラスタも表せる |
| 目的 | 距離の2乗の和 $J$ を減らす | 対数尤度を増やす |
| 計算 | 速い | 遅い。共分散行列が特異になることがある(小さな値を対角に足して防ぐ) |

すべてのクラスタの共分散行列を $\sigma^2 I$ に固定し、 $\sigma \to 0$ とすると、負担率は「最も近い中心のクラスタで 1、ほかで 0」になり、EM は k-means と同じになる。実際によく使うのは、k-means で初めの中心を決めてから、EM で混合ガウス分布を当てはめる方法である(notebook でもそうする)。

## 6. クラスタの数を選ぶ

$K$ を大きくすれば、 $J$ はいくらでも小さくなる(すべての点が自分の中心になれば 0)。対数尤度も大きくなる。そこで、

- **エルボー法**: $K$ を増やしたときの $J$ の減り方が、急に小さくなる所を選ぶ
- **情報量規準**(BIC など):対数尤度に、パラメータの数に応じた罰をつけて比べる
- **目的で決める**:分けた結果を何に使うかで決める。答えが1つに決まらないことが多い

## 7. 研究で使うときは

- **入力の大きさをそろえる**:距離を使うので、単位の違う特徴量(m と mm)を混ぜると、大きい値の特徴量だけでクラスタが決まる。標準化してから使う(S2 §5)
- **クラスタに意味があるとは限らない**:k-means は、どんなデータでも $K$ 個に分ける。分けた結果を図で確かめ、seed を変えても同じように分かれるかを確かめる
- **異常検知**:混合ガウス分布の確率密度 $p(x)$ が小さい点は、「よくあるパターン」から外れた点である。正常なデータで学習し、 $p(x)$ がしきい値より小さい点を異常とみなす方法がある
- scikit-learn では `KMeans`(`n_init` で初めの中心を変えた回数)、`GaussianMixture`(`covariance_type` で共分散の形)が、この単元と同じことをする
