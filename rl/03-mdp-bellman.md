R2 では、環境をプログラム(`step()`)として作った。この単元では、同じ環境を**数式**で書く。数式で書くと、「この方策はどれくらい良いか」(価値)を、エピソードを何度も試さずに計算できるようになる。

## 1. MDP:問題を5つの要素で書く

強化学習の問題は、次の5つで書ける。これを**マルコフ決定過程**(MDP、Markov Decision Process)という。

| 要素 | 記号 | R2 のグリッドでは |
|---|---|---|
| 状態の集合 | $\mathcal{S}$ | 16マス |
| 行動の集合 | $\mathcal{A}$ | 上・右・下・左 |
| 遷移確率 | $P(s' \mid s, a)$ | 状態 $s$ で行動 $a$ をとったとき、次の状態が $s'$ になる確率。滑る床で決まる |
| 報酬 | $R(s, a)$ | 状態 $s$ で行動 $a$ をとったときにもらう報酬の期待値 |
| 割引率 | $\gamma$ | $0 \le \gamma \le 1$ 。この単元と R4・R5 では 0.95 |

R2 の `step()` は、 $P$ と $R$ をプログラムにしたものである。

**計算機での持ち方**:状態と行動に番号をつけ、遷移確率を3次元の配列 `P[s, a, s2]`(形 `(状態の数, 行動の数, 状態の数)`)、報酬を2次元の配列 `R[s, a]` で持つ。各 `(s, a)` について、`P[s, a, :]` の和は 1 である。

### マルコフ性

MDP では、**次の状態の確率は、今の状態と行動だけで決まり、それより前の履歴にはよらない**と仮定する。これを**マルコフ性**という(M2 §6 のマルコフ連鎖に、行動を加えたもの)。

> [!NOTE]
> マルコフ性が成り立つかは、**状態の選び方**で決まる。グリッドでは「今いるマス」だけで次が決まるので成り立つ。速度を持つ台車で「位置」だけを状態にすると、次の位置は速度にもよるので成り立たない。そのときは、速度も状態に入れる。

## 2. 方策

各状態でどの行動を選ぶかの決まりを**方策**という。

- **決定的な方策**:各状態で行動が1つに決まる。 $a = \pi(s)$ と書く。配列では、長さ $\lvert \mathcal{S} \rvert$ の整数の配列
- **確率的な方策**:各状態で、行動を確率で選ぶ。 $\pi(a \mid s)$ と書く。配列では、形 `(状態の数, 行動の数)` で、各行の和が 1

## 3. 収益と割引率

時刻 $t$ より後にもらう報酬を、割引きながら足したものを**収益**という。

```math
G_t = r_{t+1} + \gamma\, r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k\, r_{t+k+1} \qquad (1)
```

- $\gamma$ が小さいほど、目先の報酬を重く見る。 $\gamma = 0$ なら、次の報酬だけを見る
- $\gamma < 1$ なら、エピソードが終わらない問題でも、収益は有限の値になる
- $k$ ステップ先の報酬は $\gamma^k$ 倍になる。 $\gamma = 0.95$ なら、20ステップ先の報酬は約 0.36 倍

式 (1) から、収益は次のように**1ステップ先の収益で書ける**。

```math
G_t = r_{t+1} + \gamma\, G_{t+1} \qquad (2)
```

この1行が、この単元の式のすべての出発点である。

## 4. 価値

方策 $\pi$ に従って動くとき、状態 $s$ から始めて得られる収益の期待値を、状態 $s$ の**価値**という。

```math
V^{\pi}(s) = \mathbb{E}_{\pi}\left[ G_t \mid S_t = s \right]
```

状態 $s$ で行動 $a$ をとり、そのあとは方策 $\pi$ に従うときの収益の期待値を、**行動の価値**という。

```math
Q^{\pi}(s, a) = \mathbb{E}_{\pi}\left[ G_t \mid S_t = s,\ A_t = a \right]
```

価値は「エピソードを何度も試して、収益を平均したもの」(M2 の標本平均)の、極限の値である。R6(モンテカルロ法)は、実際にそうやって価値を推定する。この単元では、試さずに式で計算する。

## 5. ベルマン方程式

式 (2) の両辺の期待値をとると、価値について次の式が成り立つ。

```math
V^{\pi}(s) = \sum_{a} \pi(a \mid s) \left[ R(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^{\pi}(s') \right] \qquad (3)
```

これを**ベルマン方程式**(ベルマン期待方程式)という。意味は次のとおりである。

- 方策が行動 $a$ を選ぶ(確率 $\pi(a \mid s)$)
- すぐに報酬 $R(s, a)$ をもらう
- 次の状態 $s'$ に移る(確率 $P(s' \mid s, a)$)。そこから先にもらえる収益の期待値は $V^{\pi}(s')$ である(マルコフ性により、どうやって $s'$ に来たかは関係ない)。それを $\gamma$ 倍する

行動の価値と状態の価値は、次の関係で結ばれる。

```math
Q^{\pi}(s, a) = R(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^{\pi}(s'), \qquad
V^{\pi}(s) = \sum_{a} \pi(a \mid s)\, Q^{\pi}(s, a)
```

### 連立一次方程式として解く

式 (3) は、未知数 $V^{\pi}(s)$ が両辺に出てくる、**状態の数だけの連立一次方程式**である。方策で平均した遷移行列 $P_{\pi}$ と報酬 $r_{\pi}$ を

```math
P_{\pi}(s, s') = \sum_{a} \pi(a \mid s)\, P(s' \mid s, a), \qquad r_{\pi}(s) = \sum_{a} \pi(a \mid s)\, R(s, a)
```

とおくと、式 (3) は $`v = r_{\pi} + \gamma P_{\pi} v`$ 、つまり

```math
(I - \gamma P_{\pi})\, v = r_{\pi} \qquad (4)
```

となる。M4 §4 の式と同じ形なので、`np.linalg.solve` で解ける。

## 6. 手で解いてみる

状態が3つ、行動が2つの、小さな MDP を考える。

```text
   状態0 ──「進む」(報酬 −1)──→ 状態1 ──「進む」(報酬 +2)──→ 状態2(終わり)
     ↺「待つ」(報酬 0)            ↺「待つ」(報酬 0)       ↺ 確率 0.5 で状態1 に残る
```

| 状態 | 行動 | 次の状態(確率) | 報酬 |
|---|---|---|---|
| 0 | 待つ | 0(1) | 0 |
| 0 | 進む | 1(1) | −1 |
| 1 | 待つ | 1(1) | 0 |
| 1 | 進む | 2(0.5)、1(0.5) | +2 |
| 2 | どちらも | 2(1) | 0 |

状態 2 は終わりの状態で、どの行動でもそこにとどまり、報酬は 0 とする(**吸収状態**)。こう書くと、終わりのある問題も、式 (3) のまま扱える。 $\gamma = 0.9$ とする。

**方策「いつも進む」の価値**:状態 2 の価値は 0 である。状態 1 では、式 (3) から

```math
V(1) = 2 + 0.9 \left( 0.5 \times 0 + 0.5\, V(1) \right) \quad\Longrightarrow\quad V(1) = \frac{2}{1 - 0.45} = \frac{40}{11} \approx 3.64
```

状態 0 では、

```math
V(0) = -1 + 0.9\, V(1) = -1 + \frac{36}{11} = \frac{25}{11} \approx 2.27
```

**方策「状態0 で待つ」の価値**:状態 0 では報酬 0 のまま、ずっと状態 0 にいるので、 $V(0) = 0$ である。「進む」の 2.27 より小さい。最初に −1 を払っても、そのあとの +2 のほうが大きいからである。

## 7. 最適な価値と最適な方策

すべての方策の中で、価値が最も大きいものを**最適な価値**という。

```math
V^{\ast}(s) = \max_{\pi} V^{\pi}(s)
```

有限の MDP では、**すべての状態で同時に**最適な価値を与える方策(最適な方策)が、決定的な方策の中に少なくとも1つある。最適な価値は、次の**ベルマン最適方程式**を満たす。

```math
V^{\ast}(s) = \max_{a} \left[ R(s, a) + \gamma \sum_{s'} P(s' \mid s, a)\, V^{\ast}(s') \right] \qquad (5)
```

式 (3) の「方策で平均する」が、「一番良い行動を選ぶ」($\max$)に変わっている。 $V^{\ast}$ が分かれば、最適な方策は、各状態で式 (5) の $[\ \ ]$ を最大にする行動を選べばよい。

> [!NOTE]
> 式 (5) は $\max$ を含むので、連立**一次**方程式ではない。そのため `solve` では解けない。小さな MDP なら、決定的な方策をすべて試して、一番良いものを選べる(notebook で行う)。しかし、R2 のグリッドでは決定的な方策が $4^{16} \approx 43$ 億通りあるので、すべては試せない。R4 では、式 (5) をくり返し使って解く方法(価値反復)を学ぶ。

## 8. 確認課題

1. 報酬の列が $`r_1 = -1,\ r_2 = -1,\ r_3 = -1,\ r_4 = +10`$(そのあと終わり)のとき、 $\gamma = 0$ 、 $0.5$ 、 $0.9$ 、 $1$ のそれぞれで収益 $G_0$ を計算せよ。 $\gamma = 0.9$ のとき、式 (2) が成り立つことを確かめよ
2. §6 の MDP で、方策「いつも進む」の行動の価値 $Q(0, \text{待つ})$ と $Q(0, \text{進む})$ を求めよ
3. §6 の MDP で、状態 0 で「進む」の報酬を −1 から −4 に変えると、最適な方策はどうなるか
4. R2 のグリッドで、「位置」だけを状態にしたとき、マルコフ性は成り立つか。「同じマスに2回入ると罰がある」というルールを足すと、どうなるか
5. 式 (4) で、 $\gamma = 1$ のとき、 $I - \gamma P_{\pi}$ が逆行列を持たないことがある。§6 の MDP の「待つ」方策で確かめよ
