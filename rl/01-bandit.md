強化学習では、エージェントは「今いちばん良さそうな行動」を選びたい(**活用**)。しかし、まだよく試していない行動のほうが、本当は良いかもしれない(**探索**)。この単元では、状態が1つしかない、いちばん簡単な強化学習の問題(**バンディット問題**)で、探索と活用の釣り合いのとり方を学ぶ。

## 1. バンディット問題

スロットマシンが $K$ 台ある。1回に1台を選んで引くと、報酬がもらえる。報酬は台ごとに決まった確率分布から出るが、エージェントはその分布を知らない。決まった回数 $T$ 回引いて、もらう報酬の合計をできるだけ大きくしたい。

| 言葉 | このコースでの記号 | 例(notebook) |
|---|---|---|
| 行動 | $a \in \{0, 1, \dots, K-1\}$ | 5台のどれを引くか |
| 報酬 | $r$ | 台 $a$ の平均 $\mu_a$ 、標準偏差 $\sigma_a$ の正規分布から出る |
| 行動の本当の価値 | $q(a) = \mathbb{E}[r \mid a]$ | $\mu_a$(エージェントは知らない) |
| 行動の価値の推定 | $Q(a)$ | これまでにもらった報酬から計算する |

R3 の MDP で、状態が1つだけで、行動しても状態が変わらない場合にあたる。状態が変わらないので、「今の行動が後の報酬に影響する」ことを考えなくてよい。そのぶん、探索と活用の問題だけを取り出して考えられる。

## 2. 行動の価値を推定する

行動 $a$ の価値は、 $a$ を選んだときにもらった報酬の**標本平均**で推定できる(M2 §3)。 $a$ を $n$ 回選んで、報酬 $`r_1, \dots, r_n`$ をもらったとき、

```math
Q_n = \frac{r_1 + r_2 + \cdots + r_n}{n}
```

である。毎回すべての報酬を足し直さなくても、1つ前の推定 $Q_{n-1}$ から計算できる。

```math
Q_n = Q_{n-1} + \frac{1}{n} \left( r_n - Q_{n-1} \right) \qquad (1)
```

(両辺に $n$ を掛けると、 $`n Q_n = (n-1) Q_{n-1} + r_n`$ となり、合計の式と一致する。)

式 (1) は、強化学習の多くの更新式に共通する形をしている。

```math
\text{新しい推定} = \text{古い推定} + \text{ステップサイズ} \times \left( \text{目標} - \text{古い推定} \right)
```

カッコの中 $`r_n - Q_{n-1}`$ は「予測の外れ」(誤差)である。予測より大きな報酬をもらったら $Q$ を上げ、小さければ下げる。ステップサイズ $1/n$ は、回数が増えるほど小さくなるので、推定は落ち着いていく。

> [!NOTE]
> ステップサイズを一定の値 $\alpha$(例:0.1)にすると、 $Q$ は**最近の報酬ほど重く見た平均**になる。 $k$ 回前の報酬の重みは $\alpha (1 - \alpha)^k$ で、古い報酬の影響は指数的に小さくなる。報酬の分布が時間とともに変わる問題では、こちらが向いている(notebook §7)。R7 の Q学習でも、一定の $\alpha$ をよく使う。

## 3. 探索の方法

### 3.1 greedy(いつも活用する)

いつも $Q(a)$ が最大の行動を選ぶ。たまたま最初に良い報酬が出た台にこだわり、本当に良い台を一度も十分に試さないことがある。

### 3.2 ε-greedy

確率 $\varepsilon$ で全行動から一様に選び(探索)、確率 $1 - \varepsilon$ で $Q$ が最大の行動を選ぶ(活用)。 $Q$ が最大の行動が $m$ 個あるとき(同点)、各行動を選ぶ確率は

```math
\pi(a) = \begin{cases} \dfrac{\varepsilon}{K} + \dfrac{1 - \varepsilon}{m} & (a \text{ が } Q \text{ の最大の行動の1つ}) \\ \dfrac{\varepsilon}{K} & (\text{それ以外}) \end{cases} \qquad (2)
```

である。

> [!WARNING]
> **同点の扱い**:`np.argmax(Q)` は、最大値が複数あると、いちばん小さい番号を返す。最初は $Q$ がすべて 0 で同点なので、これを使うと行動 0 ばかりを選んでしまう。同点のときは、最大の行動の中からランダムに選ぶ(式 (2))。

### 3.3 楽観的な初期値

$Q$ の初期値を、ありうる報酬より大きな値(例:10)にしておく。どの行動も、試すと $Q$ が下がるので、まだ試していない行動が「良さそう」に見える。その結果、greedy でも、最初のうちはすべての行動を試す。簡単だが、探索は最初だけで終わる。

### 3.4 UCB(信頼区間の上限)

推定 $Q(a)$ に、「まだよく分かっていない分」を足した値が最大の行動を選ぶ。

```math
a_t = \operatorname*{argmax}_a \left[ Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right] \qquad (3)
```

$N_t(a)$ は、時刻 $t$ までに $a$ を選んだ回数である。あまり選んでいない行動ほど、足す値が大きい。標本平均のばらつきは $1/\sqrt{N}$ で小さくなる(M2 §3)ので、 $\sqrt{1/N_t(a)}$ は「推定がどれだけ不確かか」を表している。 $\ln t$ は、時間がたつと、あまり選ばれていない行動をまた試すようにするための項である。 $N_t(a) = 0$ の行動は、先に1回ずつ試す。

## 4. 方法を比べる

報酬は乱数で出るので、1回の実行の結果だけでは、方法の良し悪しは分からない(M2 §3)。

- 同じ設定で、seed を変えて何回も(notebook では 100 回)実行し、**各時刻での平均**を比べる
- 比べる量は、(1)各時刻の**平均の報酬**、(2)各時刻に**最適な行動を選んだ割合**の2つ
- すべての方法で、環境・ステップ数・実行の回数をそろえる

> [!IMPORTANT]
> 研究で手法を比べるときも、同じである。**1つの seed の結果で「この手法が良い」と言わない**。複数の seed の平均と、ばらつき(標準偏差や、その範囲の図)を示す。

典型的には、次のような結果になる。

| 方法 | 最初のうち | 長い目で見ると |
|---|---|---|
| greedy | 良い台に気づかないことがある | 最適な行動の割合が低いまま |
| ε-greedy | ゆっくり良くなる | $\varepsilon$ の分だけ探索を続けるので、最適な行動の割合は $1 - \varepsilon + \varepsilon/K$ 程度で止まる |
| 楽観的な初期値 | 最初に全部試すので、報酬が一時的に下がる | 定常な問題では良い |
| UCB | 不確かな行動を試す | 良いことが多い。 $c$ の選び方で変わる |

## 5. 研究で使うときは

- **探索の量は、ハイパーパラメータ**である。 $\varepsilon$ 、 $c$ 、初期値を変えると結果が変わる。研究では、どの値を使ったかを必ず記録する
- **報酬の大きさ(スケール)に注意する**:UCB の $c$ や楽観的な初期値は、報酬の大きさに合わせて決める必要がある
- **深層強化学習でも同じ考え方を使う**:DQN の ε-greedy(R10)、方策のエントロピーを使った探索など

## 7. 確認課題

1. ある行動を4回選び、報酬が 3, 5, 4, 8 だった。式 (1) を使って、 $`Q_1, Q_2, Q_3, Q_4`$ を順に計算せよ。最後の値が4つの平均と一致することを確かめよ
2. $K = 5$ 、 $\varepsilon = 0.1$ で、 $Q = (2, 5, 5, 1, 0)$ のとき、式 (2) で各行動を選ぶ確率を求めよ。和が 1 になることを確かめよ
3. ステップサイズを一定の $\alpha = 0.5$ にしたとき、3回前の報酬の重みはいくつか。 $\alpha = 0.1$ ではどうか
4. ε-greedy($\varepsilon = 0.1$ 、 $K = 5$)で、 $Q$ が正しく推定できたあと、最適な行動を選ぶ割合はいくつか
5. 1回の実行で、方法 A の平均報酬が方法 B より大きかった。これだけで「A のほうが良い」と言えないのはなぜか
