R7 の Q学習は、行動の価値 $Q(s, a)$ を学び、価値が最大の行動を選んだ。この単元では、価値を経由せずに、**方策そのもの**をパラメータで表して学ぶ。題材は、台車の上の棒を倒さないように支える **CartPole** である。

## 1. なぜ方策を直接学ぶのか

価値を学んで $\max$ で行動を選ぶ方法(R7)には、次の弱点がある。

- **行動が連続のとき**:ロボットの関節のトルクのように行動が連続だと、 $\max_a Q(s, a)$ を毎回求めるのが難しい
- **確率的な方策が必要なとき**:相手のいるゲームや、状態が一部しか見えない問題では、行動を確率的に選ぶ方策が最適になることがある。 $\max$ で選ぶ方策は決定的である
- **小さな変化**:価値が少し変わっただけで、 $\max$ で選ぶ行動が急に入れ替わる。方策を直接動かすと、確率が少しずつ変わる

## 2. 方策をパラメータで表す

状態 $s$ を数のベクトル(CartPole では、台車の位置・速度、棒の角度・角速度の4つ)で表す。行動が $K$ 個のとき、各行動の「好ましさ」を状態の一次式 $w_k^\top s$ で表し、**ソフトマックス関数**で確率にする。

```math
\pi_W(a \mid s) = \frac{\exp(w_a^\top s)}{\sum_{k} \exp(w_k^\top s)} \qquad (1)
```

$W$ は、 $w_k^\top$ を行として並べた $K \times 4$ の行列である。好ましさが大きい行動ほど、選ぶ確率が大きい。すべての行動に、正の確率が残るので、探索も自然に行われる。

> [!TIP]
> ソフトマックスは、S5 のロジスティック回帰の多クラス版(ソフトマックス回帰)と同じ式である。 $K = 2$ なら、 $`\pi(1 \mid s) = \sigma((w_1 - w_0)^\top s)`$ (シグモイド関数)になる。

## 3. 目的関数と方策勾配

方策の良さを、スタートからの収益の期待値で測る。

```math
J(W) = \mathbb{E}_{\pi_W}\left[ G_0 \right]
```

$J$ を大きくしたいので、勾配 $\nabla_W J$ の方向に $W$ を動かす(勾配**上昇**)。問題は、 $J$ が「方策に従って動いたときの期待値」なので、 $W$ で微分する方法がすぐには分からないことである。環境の遷移確率も、期待値の中に入っている。

### 1ステップの場合で考える

まず、状態が1つで、1回行動したら終わる場合(R1 のバンディット)を考える。行動 $a$ の報酬の期待値を $q(a)$ とすると、

```math
J = \sum_a \pi(a)\, q(a), \qquad \nabla J = \sum_a \nabla \pi(a)\, q(a)
```

ここで、 $\nabla \pi(a) = \pi(a) \nabla \log \pi(a)$ (対数の微分 $\nabla \log \pi = \nabla \pi / \pi$ を変形したもの)を使うと、

```math
\nabla J = \sum_a \pi(a)\, q(a)\, \nabla \log \pi(a) = \mathbb{E}_{a \sim \pi}\left[ r\, \nabla \log \pi(a) \right] \qquad (2)
```

となる。右辺は「方策に従って行動 $a$ を選び、報酬 $r$ をもらい、 $r \nabla \log \pi(a)$ を計算する」ことの期待値である。つまり、**実際に行動してみた結果から、勾配を推定できる**。報酬の分布(環境のモデル)を知らなくてよい。

### 何ステップも続く場合:方策勾配定理

エピソードが何ステップも続く場合も、同じ考え方で次の式が導ける(**方策勾配定理**。導出は補足の資料を見る)。

```math
\nabla J = \mathbb{E}_{\pi}\left[ \sum_{t} G_t\, \nabla \log \pi(a_t \mid s_t) \right] \qquad (3)
```

時刻 $t$ の行動の対数確率の勾配に、**その時刻から後の収益** $G_t$ を掛ける。時刻 $t$ より前の報酬は、時刻 $t$ の行動では変えられないので、掛けない。

意味は単純である。収益が大きかった行動の確率を上げ、小さかった行動の確率を下げる。

## 4. REINFORCE

式 (3) の期待値を、1エピソードの結果で置き換え、勾配上昇する。

1. 今の方策で1エピソード動かし、 $`(s_t, a_t, r_{t+1})`$ を記録する
2. 各時刻の収益 $G_t$ を、後ろから $`G_t = r_{t+1} + \gamma G_{t+1}`$ で計算する(R3 の式 (2))
3. 各時刻について、 $`W \leftarrow W + \alpha\, G_t\, \nabla_W \log \pi_W(a_t \mid s_t)`$

ソフトマックス方策 (1) では、 $\nabla \log \pi$ は次の簡単な形になる(notebook で導いて、数値微分で確かめる)。

```math
\nabla_{w_k} \log \pi(a \mid s) = \left( [a = k] - \pi(k \mid s) \right) s \qquad (4)
```

$[a = k]$ は、 $a = k$ なら 1、そうでなければ 0。「選んだ行動の好ましさを上げ、方策が選びそうだった行動の好ましさを下げる」という形で、S5 のロジスティック回帰の勾配(予測と正解の差 × 入力)と同じ形をしている。

> [!WARNING]
> **勾配の実装は、必ず数値微分で確かめる**(M3)。勾配の符号や添字を間違えても、プログラムはエラーにならず、「学習がなんとなく遅い」「うまくいかない」という形でしか現れない。

## 5. ばらつきとベースライン

式 (3) の推定は、1エピソードの結果から作るので、**とてもばらつく**。CartPole では、どの行動をとっても報酬は毎ステップ +1 なので、 $G_t$ はいつも正である。すると、どの行動の確率も上げようとし、「他より良かったか」は、上げ幅の差だけで表される。

そこで、収益から、行動によらない値 $b$(**ベースライン**)を引く。

```math
\nabla J = \mathbb{E}_{\pi}\left[ \sum_t \left( G_t - b \right) \nabla \log \pi(a_t \mid s_t) \right] \qquad (5)
```

$b$ を引いても、期待値は変わらない(**偏りが入らない**)。確率の和は 1 なので $\sum_a \nabla \pi(a \mid s) = \nabla 1 = 0$ 、つまり $`\mathbb{E}_{a \sim \pi}[b\, \nabla \log \pi(a \mid s)] = b \sum_a \nabla \pi(a \mid s) = 0`$ だからである。期待値は同じで、ばらつきだけが小さくなる。 $b$ として、収益の平均を使うことが多い。

notebook では、さらに収益を標準偏差で割る(**標準化**)。これは、ベースラインに加えて、ステップサイズを自動で調整していることにあたり、学習が安定する。

> [!NOTE]
> ベースラインを、状態ごとの価値 $V(s_t)$ にして、それも同時に学ぶと **actor-critic** になる。 $`G_t - V(s_t)`$ は「平均より良かった分」で、**アドバンテージ**という。研究でよく使う **PPO** は、アドバンテージを使った方策勾配に、「1回の更新で方策を変えすぎない」工夫を加えたものである。

## 6. 研究で使うときは

- **学習曲線は、複数の seed で**:方策勾配法は、seed による違いが特に大きい。1つの seed の結果で判断しない
- **ステップサイズに敏感**:大きすぎると、方策が一気に偏って戻れなくなる(ある行動の確率がほぼ 1 になると、勾配がほぼ 0 になる)。小さすぎると進まない
- **割引率**:CartPole では、 $\gamma$ が 1 に近いほど、「長く立たせる」ことを重く見る。 $\gamma = 1$ だと、エピソードの前半の $G_t$ がとても大きくなり、ばらつきが増える

## 7. 研究室のライブラリ `cpai_lab` との関係

`cpai_lab` には、方策勾配法は入っていない。研究では、PyTorch で書かれた強化学習のライブラリ(例:Stable-Baselines3)の PPO などを使うことが多い。そのとき、中で計算している式は、この単元の式 (3)〜(5) を出発点にしている。ライブラリの設定(学習率、割引率、エントロピーの係数など)の意味が分かるように、この単元の notebook で、小さな問題を自分で動かしておく。

## 8. 確認課題

1. 行動が2つ($K = 2$)、状態 $s = (1, 2)$ 、 $`W = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}`$ のとき、 $\pi(0 \mid s)$ と $\pi(1 \mid s)$ を求めよ。行動 1 を選んだとき、式 (4) で $\nabla_W \log \pi(1 \mid s)$ を求めよ
2. 報酬の列が $1, 1, 1$ (そのあと終わり)のとき、 $\gamma = 0.9$ で $`G_0, G_1, G_2`$ を求めよ
3. 式 (2) で、すべての行動の報酬に定数 $c$ を足しても、 $\nabla J$ は変わらないことを示せ
4. CartPole で、ベースラインを使わないと学習が不安定になりやすいのはなぜか。「 $G_t$ はいつも正」という点から説明せよ
5. 方策のある行動の確率がほぼ 1 になると、学習が止まりやすいのはなぜか。式 (4) から説明せよ
